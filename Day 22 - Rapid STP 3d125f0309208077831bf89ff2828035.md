### What appears different than what you have learned about the root bridge?

1. Something different that I see would be interface f0/3
    1. Role: Back
    2. Status: BLK (Blocking)
2. Usually, a root bridge has only designated ports, but port f0/3 Role Status is Back
    1. Why? Because each collision domain has one designated port. Since the hub is a collision domain and two ports are connected to it, only one can be designated, making the one on the root bridge the backup port.
